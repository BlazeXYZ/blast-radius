    Runs entirely in your browser. The only requests go to public APIs: the npm registry, PyPI, OSV.dev and GitHub.

    Every dependency is a dependency on someone else's dependencies.

    A typical app lists a dozen packages and installs hundreds. Blast Radius resolves your full tree, then shows which packages are dangerous, how deep they're buried, and which of your choices pulled them in.

    • Known CVEs from OSV.dev, with the version that fixes each one
    • Supply-chain signals: install scripts, single maintainers, abandoned and deprecated packages
    • Blast radius: what each direct dependency costs you, and what disappears if you drop it
